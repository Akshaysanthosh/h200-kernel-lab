# Contributing

Start with the benchmark methodology and experiment ledger. Propose a concrete hypothesis with a target shape, correctness requirements, comparison baseline and stop rule. Preserve all champion files and their hashes.

Record source provenance, environment, GPU, library versions, preparation time, paired timings, A/A controls and independent-weight results. Clearly label development results versus official checks versus scored submissions. Do not report a speedup from a single favorable sample.

Do not add credentials, billing records, private inputs or model weights. No workflow in this repository automatically launches GPU jobs or submits challenge entries. Run the CPU-only artifact verifier before proposing a change.
